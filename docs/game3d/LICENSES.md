# Godot fight (app/game3d): asset licences

Every file under `app/game3d/art/` is listed here with its source and licence. Nothing is
from Mixamo, Sketchfab or a ripped game, and nothing came from an AI image service.

The project's own CC0 sets below were made for the earlier Unity street build
(costquest-unity, branch `street-look`, commit 47560e4) and are copied here as plain files.
No Unity software was installed or run for this; the files were read from an existing
checkout on the farm (`~/cq-work/game-godot/ext/unity-ref`, cq 061's read-only copy).
